## Overview

The Sims 4 SNB Bills Tracker is a companion spreadsheet and calculator for the SNB Bills mod, helping players manage household finances by tracking income sources, recurring bills, mortgage payments, and utility costs. It calculates surplus income and helps plan purchases to keep Sims households financially stable.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **The Sims 4 SNB Bills Tracker** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Income Tracking** | Record and categorize all household income sources by type |
| **Bill Schedule** | Track recurring SNB bill amounts and their weekly due dates |
| **Mortgage Calculator** | Calculate mortgage payment schedules for the SNB property system |
| **Budget Planner** | Monthly surplus calculator helping plan purchases without debt |
